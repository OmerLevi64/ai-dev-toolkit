# Security Policy

## Reporting a vulnerability

This toolkit is dependency-free utility code and prompt text, but if you
find a security issue (e.g., a prompt template that leaks secrets, or
unsafe handling in an example), please open a GitHub issue with the
`security` label — do not post exploit details publicly before a fix
exists.

## Scope

- `src/` utilities: treated as library code; issues fixed promptly.
- `prompts/` and `guides/`: content issues (bad advice, insecure
  suggestions) are fixed like bugs.
